# Data Directory

This folder should contain the NBA dataset downloaded from Kaggle.

## Setup Instructions

1. Visit: https://www.kaggle.com/datasets/wyattowalsh/basketball
2. Download the dataset
3. Place the plays data file here as `nba_plays.csv`

## Required Columns

The CSV file should contain:
- GAME_ID
- PLAYER_NAME  
- SHOT_DISTANCE
- EVENT_TYPE (values: "Made Shot" or "Missed Shot")

**Note**: This file is not included in the repository due to size and licensing.
